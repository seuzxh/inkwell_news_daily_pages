## AI & ML

**Vibe coding and agentic engineering are getting closer than I'd like**
▸ Simon Willison 在 High Leverage 播客中深入探讨 AI 编程工具的现状。核心观点：Vibe Coding（氛围编程）与 Agentic Engineering（智能体工程）正在快速融合，AI 不仅生成代码，还在重新定义开发流程。关键数据：Anthropic 的 Claude Code 正在挑战 GitHub Copilot 的主导地位，Cursor 内部测试显示 AI 代码完成率从 58% 提升至 70%。
🔗 https://simonwillison.net/2026/May/6/vibe-coding-and-agentic-engineering/

**Live blog: Code w/ Claude 2026**
▸ Simon Willison 在 Anthropic「Code w/ Claude 2026」大会现场实时博客。涵盖 Claude Code 新功能发布、AI 编程助手的最新进展，以及 Claude 4.7 系列在代码能力上的突破。大会聚焦 Agentic Coding 场景，Anthropic 展示了多步骤自动化代码生成的演示。
🔗 https://simonwillison.net/2026/May/6/code-w-claude-2026/

**Silicon Valley gets Serious about Services**
▸ Latent Space 分析硅谷 AI 服务化趋势。核心洞察：模型厂商正在从纯 API 模式转向「模型+服务」组合，OpenAI、Anthropic、谷歌均推出企业级 Agent 解决方案。市场预测：2026 年 AI Agent 市场将突破 500 亿美元，代码生成和企业自动化是最大细分市场。
🔗 https://www.latent.space/p/ainews-silicon-valley-gets-serious

## Systems

**Why not have changes in API behavior depend on the SDK you link against?**
▸ Raymond Chen 在微软老牌博客 deep dive Windows API 行为差异问题。核心问题：同一 API 在不同 SDK 版本下可能返回不同结果，导致兼容性问题。分析：SDK 版本控制比应用版本更关键，建议开发者在 CI/CD 中固定 SDK 版本以确保构建可复现性。
🔗 https://devblogs.microsoft.com/oldnewthing/20260506-00/?p=112303

## Essays

**Asimov's three laws are merely a suggestion**
▸ Ibrahim Diallo 从哲学和技术角度探讨 AI 伦理。核心观点：阿西莫夫三定律本质上是一套软约束，无法真正阻止 AI 伤害人类。现代 AI 安全需要：多层防护机制 + 实时监控 + 法律框架。反思：为什么规则总是被打破？因为规则本身无法适应复杂现实。
🔗 https://idiallo.com/blog/asimov-three-laws-dont-work-with-ai
